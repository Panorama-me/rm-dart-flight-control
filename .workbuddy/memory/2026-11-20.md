
## 攻角增益改为凹递增函数（提交 3f04e7b）

`G(|raw|) = MIN + (MAX-MIN)*|raw|/(|raw|+RAW_HALF)`，MIN=0.50 / MAX=1.15 / RAW_HALF=3.5°。
二阶导恒小于 0（斜率 0.142@0.5° → 0.017@8°）。用有理式不用 expf（F103 无 FPU）。

**关键发现：焦距严重偏小。**
- yaw 轴回归 `yaw ~ atan(dx/f)`：f = **1210 px**，R²=0.83，残差 1.50°（f=480 时 5.28°）。
- pitch 轴独立拟合：f = **1250 px**，残差 0.69°（f=480 时 3.36°）。
- 各 |dx| 分箱残差不随幅值漂移 → 不是镜头畸变造成的假象。
- 若 480 正确，`atan(dx/480)` 变化 31.5°，而 INS 只记录 12°，等于目标在 3 秒内自己移动 10°，5 段都如此——不可能。

**若成立（待卷尺确认）**：所有角度和角速率被放大 480/1210 ≈ 2.5 倍，
等效 Kp 14→35、Ki 25→62.5、Kd 3→7.5，前视项 `0.2s×ω` 同样 ×2.5。
改焦距后必须按 0.4 缩放 PID，否则等于把增益砍掉 60%。

**确认方法（5 分钟）**：目标放正前方 L=3.0 m、横移 W=0.50 m（真角 9.46°），
读 `vis_x_px`：约 202 px → f=1210；约 80 px → f=480。
