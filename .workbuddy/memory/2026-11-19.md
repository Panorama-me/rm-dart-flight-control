## 11.19 数据离线重放（10 发，telem_00006~00015）

数据位置：`D:/Study/rmElectric/rm_dart_test/内录/11.19/`。

- **11.19 实飞是 MODE 0（角度 PID）**，不是 PN：`|yaw_u|` 峰值 420（PID 限幅），
  加速度环限幅是 250，回归 `yaw_u = Ka*a_cmd - Ka*a_meas - Kq*gz` 得 Ka=63.5、R²=0.37，不成立。
- `frame` 列是**遥测包序号**，不是视觉帧号。视觉帧只能用 `rel = los_yaw - yaw` 的阶跃重建。
- 重放模型：raw = -Δrel/dt → LPF → pn = -rate + gz。旧参数重放 71.3% 与机上实测 71.5% 吻合。
- 持续运动段（|rel_dot|>3 且连续同向，157 帧/9 发）符号一致率：**67.4% → 79.8%**；
  RMSE 40.5 → 35.6 °/s；帧间抖动 19.9 → 19.2（未恶化）。孤立跳变帧占 7.6%。
- 舵偏：实测 PID RMS 131 µs / p95 313 µs；新 PN 理论 RMS 38 µs / p95 53~78 µs，无饱和。
- 局限：目标在动（los 波动 12~82°），无法闭环保真；遥测 45 Hz 与视觉异步，R² 中位仅 0.42~0.67。

## main.py 加在线焦距标定（陀螺仪光流法）

在 `main.py`（OpenMV 上位机，UTF-8+LF）加了直接标定焦距的方案，区别于既有
`tools/calib_main.py`+`fit_focal_csv.py`（那是离线用 yaw 角度回归 tan 模型）：

- 原理：目标绿灯固定，手动转动机体，`f = -(d(cx)/dt)/gyro_z`、`f = -(d(cy)/dt)/gyro_y`，
  相邻帧差分做最小二乘（斜率=-f），在线滑动输出。
- 单位与固件 `DART_CAMERA_FOCAL_*_PX` 一致（320px 图 + 36.9° 视场 => 480）。
- 新增：配置段（`FOCAL_CALIB_ENABLE/MIN_RATE_DPS/MIN_SAMPLES/PRINT_MS/OUT_FILE`、
  `DEG_TO_RAD`）+ 状态/函数（`focal_calib_active/feed/result/tick`）+ 主循环喂数、
  1 Hz 打印落盘、叠加显示、finally 里写最终 RESULT。
- 只在台架生效：`FOCAL_CALIB_ENABLE && telem_link && (flags&F_IMU_READY) && 未起飞(3..5)`，
  不碰 send_target，飞行时自动停。
- 精度（仿真）：±10° 摆动 0.5% 偏、±15° 1.5%、±20° 2.9%、±25° 4.8%（tan 非线性）。
  建议 ±10~15°。小角度近似，不引入 gyro 积分，对陀螺零偏鲁棒。
- 已自检：UTF-8、纯 LF（CRLF=0）、`compile()` 语法通过。未动固件/文档。
