## 1. 系统概览

### 1.1 组成

工程由两个控制器组成，通过一路 UART 双向通信：

- **STM32F103C8T6 飞控**：BMI088 姿态解算、起飞检测、上升段姿态保持、下降段视觉引导、四路舵机 PWM、握手与 50 Hz 遥测。
- **OpenMV 视觉端**：绿色目标识别、偏移量上行、遥测解析与屏幕叠加、原生图像录像与遥测 CSV 记录。

控制对象为带 **X 型尾翼、四舵机** 的小型飞行器。一次飞行的时间线：

```text
上电 → IMU 静止标定 → 舵机回中 → 等待起飞 → 起飞检测
     → 上升段（保持 yaw/roll，pitch 两阶段补偿，可选视觉 yaw）
     → 下降段（视觉前视追踪引导 pitch/yaw，roll 保持）
```

### 1.2 能力与边界

| 能力 | 实现情况 |
|---|---|
| 双 MCU 双向串口通信 | 有，115200 8N1，CRC8 校验 |
| 视觉目标识别与偏移输出 | 有，OpenMV 绿色色块 + 跟踪 ROI |
| 姿态解算 | 有，BMI088 + 四元数 EKF |
| 起飞检测 | 有，去重力机体 X 轴加速度 + 连续确认 |
| 上升段姿态保持 | 有，yaw/roll 保持起飞姿态；pitch 补偿到目标角后锁存 |
| 上升段视觉 yaw | 有，识别到目标时 yaw 切视觉，脱锁回自稳 |
| 下降段视觉引导 | 有，前视追踪 + 视觉 PID + X 尾混控 |
| 飞行状态遥测 | 有，37 字节、50 Hz（含 LOS 增量与四路舵机角） |
| 模式握手 | 有，下位机决定 default/pitch/yaw/both |
| 机载录像 / 遥测记录 | 有，ImageIO 原生流 + 逐帧 CSV |
| 地面站 / 无线链路 | **没有** |
| GPS / 磁力计 / 测距 / 空速 | **没有** |
| 着陆检测 / 失控保护 / 目标搜索 | **没有** |

### 1.3 八条关键结论

1. 当前协议是 **37 字节遥测 + 8 字节视觉帧 + 5 字节握手 / 4 字节 ACK / 4 字节复位**，旧版本文档中的 10/14 字节帧已不存在。
2. 遥测发送的启动条件是 **收到 OpenMV 的握手 ACK**（`attitude_tx_armed`），不是“收到第一帧视觉帧”；OpenMV 上电会先发复位帧清除该标志。
3. OpenMV **必须先完成握手才进入主循环**，单独给 OpenMV 上电会停在 `waiting handshake...`。
4. PID 的微分项使用 **BMI088 陀螺角速度**（`Dout = -Kd × 角速度`），不是对角误差求导；`DART_PID_OLS_ORDER = 0`。
5. 视觉滤波默认 **RAW_RATE**：位置角不做低通，只用当前帧的 `atan`；角速率做一阶低通。原 EKF 通过 `DART_VISION_FILTER_MODE` 可切回。
6. 上升段 pitch 采用两阶段：未低头到目标角时输出固定抬升 100 µs，低头后转 PID 闭环；回到目标角后锁存为 0。
7. 下降段默认保留最后一次视觉指令（`DART_DESCENT_LOCK_LAST_VISUAL_COMMAND_ENABLE = 1`），最长保持 `DART_TARGET_REACQUIRE_RESET_MS = 500 ms`。
8. `main()` 只初始化 GPIO / SPI1 / TIM2 / USART1；USB、USART3、TIM3 的函数仍在文件中但不再调用，`defaultTask` 已删除，共 3 个任务。

## 2. 硬件平台与接线

### 2.1 主控

| 项目 | 配置 |
|---|---|
| MCU | STM32F103C8T6，LQFP48 |
| 内核 / 主频 | Cortex-M3，72 MHz（HSE 12 MHz × 6） |
| Flash / RAM | 64 KB / 20 KB |
| HAL 时基 | TIM1 更新中断（`stm32f1xx_hal_timebase_tim.c`） |
| RTOS | FreeRTOS 10.0.1，CMSIS-RTOS v2，tick 1 kHz，heap_4，10 KB |
| 工具链 | Keil MDK，ARMCC V5.06（最近构建日志为 update 6 build 750） |
| CubeMX | 6.18.1，`MA_DartGuide.ioc` |

### 2.2 引脚分配

来自 `gpio.c` / `tim.c` / `usart.c` / `spi.c` / `main.h`：

| 功能 | 引脚 | 说明 |
|---|---|---|
| 舵机 PWM 1–4 | PA0 / PA1 / PA2 / PA3 | TIM2 CH1–CH4，50 Hz |
| RGB LED 红 / 绿 / 蓝 | PA4 / PA5 / PA6 | 低电平点亮（`DART_LED_ACTIVE_LEVEL`） |
| 视觉串口 TX / RX | PA9 / PA10 | USART1，115200 8N1 |
| IMU SPI SCK / MISO / MOSI | PB3 / PB4 / PB5 | SPI1 重映射，MISO 上拉 |
| 陀螺 CS / INT | PB12 / PB13 | INT 配置为上升沿中断，控制中未使用 |
| 加速度 CS / INT | PB14 / PB15 | INT 配置为上升沿中断，控制中未使用 |
| USB DM / DP | PA11 / PA12 | 不再初始化，`usb.c` 仍参与编译 |
| USART3 | PB10 / PB11 | `usart.c` 保留初始化函数，`main()` 不调用 |
| CAN | PB8 / PB9 | GPIO 与重映射仍配置，无 CAN 外设初始化 |

TIM2 时基：预分频 71（1 MHz 计数）、周期 19999，即 20 ms / 50 Hz。

### 2.3 舵机索引与通道映射

`set_servo_compare()` 的索引与定时器通道不是顺序对应的，换线或改混控前必须核对：

| 索引 | 定时器通道 | 引脚 |
|---|---|---|
| 0 | TIM2_CH3 | PA2 |
| 1 | TIM2_CH2 | PA1 |
| 2 | TIM2_CH1 | PA0 |
| 3 | TIM2_CH4 | PA3 |

### 2.4 与 OpenMV 的接线

| OpenMV | F103 | 方向 |
|---|---|---|
| UART3 TX（常见 P4） | PA10 / USART1_RX | OpenMV → F103，视觉帧 |
| UART3 RX（常见 P5） | PA9 / USART1_TX | F103 → OpenMV，握手 + 遥测 |
| GND | GND | 必须共地 |

双方均为 3.3 V TTL，不要接 RS232 电平。具体 UART3 引脚以所用 OpenMV 型号为准。

### 2.5 电源与执行机构

- 四路舵机由 TIM2 输出 50 Hz PWM，中位 1550 µs，行程 550–2550 µs。
- 每个控制周期（2 ms）脉宽变化限制 30 µs，从一端到另一端约需 67 ms。
- 首次测试必须拆除动力或牢固约束机体，先确认中位、方向、限位与 LED，再上动力。
- BMI088 上电做 6000 点静止零偏标定；标定期间机体必须完全静止。

## 3. 软件架构与启动时序

### 3.1 分层

```text
┌──────────────────────────── OpenMV ────────────────────────────┐
│ main.py                                                        │
│  传感器初始化 → 等待握手 → 目标识别 → 视觉帧 → 遥测解析        │
│  → 屏幕叠加 → ImageIO 录像 + 遥测 CSV                          │
└───────────────────────────┬────────────────────────────────────┘
                            │ UART3 / USART1，115200 8N1
┌───────────────────────────┴────────────────────────────────────┐
│ STM32F103                                                      │
│  Core: HAL / 时钟 / FreeRTOS                                   │
│  ins_task.c: BMI088 → QuaternionEKF → INS                     │
│  Control_Task.c: 状态机 / 视觉滤波 / 引导 / PID / 混控 / 遥测   │
│  bsp: DWT 计时、PWM、LED、UART 中断                            │
│  TIM2 → 四路舵机                                               │
└────────────────────────────────────────────────────────────────┘
```

### 3.2 FreeRTOS 任务

| 任务 | 优先级 | 栈 | 周期 | 工作 |
|---|---|---:|---|---|
| `IMU_Task`（`Ins_Task`） | Normal | 2048 B | 1 ms | BMI088 初始化与标定（失败每 100 ms 重试）、`INS_Task()` |
| `Control_Task`（`CTL_Task`） | Normal | 1024 B | 2 ms | `control_Task()` 状态机与控制 |
| `led_task`（`LED_Task`） | Low | 512 B | 20 ms | LED、50 Hz 遥测、100 ms 握手 |

- IMU 与 CTL 同优先级，实际执行顺序由 1 ms tick 时间片轮转决定；INS 快照用关中断 `memcpy` 保证一致性。
- 三个任务栈都从 10 KB FreeRTOS heap 动态分配；主栈 2 KB、传统 heap 512 B 也计入 RAM。

### 3.3 数据流

```text
BMI088 ──SPI1──> INS_Task ──INS──> Control_Task ──TIM2 PWM──> 四舵机
                                      ▲
OpenMV 视觉帧 ──USART1 IRQ──> mailbox ┘
                                      │
Control_Task ──50 Hz 遥测──> USART1 IT ──> OpenMV 显示 / 录像 / CSV
```

### 3.4 启动时序

1. F103 上电：`HAL_Init()`、`SystemClock_Config()`（HSE 12 MHz × 6 = 72 MHz），依次调用 `MX_GPIO_Init()`、`MX_SPI1_Init()`、`MX_TIM2_Init()`、`MX_USART1_UART_Init()`，再 `DWT_Init()`；随后 `osKernelInitialize()` + `MX_FREERTOS_Init()` 创建 3 个任务。
2. `IMU_Task` 先 `control_notify_imu_ready(0)`，然后循环 `BMI088_init(&hspi1, 1U)`（每 100 ms 重试，含 6000 点静止标定），成功后 `INS_Init()`、`INS_Task()`，置 `imu_ready = 1`，进入 1 ms 姿态循环。
3. `Control_Task` 执行 `control_Init()`：清空运行时结构（保留 IMU 标志）、初始化 5 个 PID、计算一次焦距、启动 USART1 单字节中断接收、状态置 `READY`。
4. `LED_Task` 每 20 ms 调用 `led_Task()`、`attitude_telemetry_send()`、`openmv_handshake_send()`。
5. OpenMV 上电：`init_sensor()`，然后 `wait_for_handshake()`——连发 3 次复位帧 `5B 5B 5B CRC`，清空接收缓冲，等待 `A5` 握手帧。
6. F103 每 100 ms 发一次握手（armed 前）；OpenMV 收到合法握手后回 3 次 ACK `5A MODE FE CRC`，清空缓冲并进入主循环。
7. F103 收到 ACK 后 `attitude_tx_armed = 1`，开始 50 Hz 遥测；OpenMV 主循环开始发视觉帧。
8. IMU 就绪后，F103 在 `IMU_READY` 等 500 ms，启动 TIM2 PWM、四舵回中，进入 `SERVO_READY` 等待起飞。

## 4. 通信协议

### 4.1 物理层

| 项目 | 值 |
|---|---|
| 波特率 | 115200 |
| 数据位 / 停止位 / 校验 | 8 / 1 / None |
| 流控 | 无 |
| OpenMV 端口 | `UART(3)`，`read_buf_len = 2048` |
| F103 端口 | USART1，PA9 / PA10，中断优先级 5 |
| 字节序 | 所有多字节整数为**大端** |

### 4.2 CRC8

三个协议共用同一实现：初值 `0x00`、多项式 `0x8C`、反射（LSB-first），与 `main.py` 的 `crc8_lsb()` 完全一致。

```text
crc = 0x00
for byte in data:
    crc ^= byte
    for _ in range(8):
        crc = ((crc >> 1) ^ 0x8C) & 0xFF if crc & 1 else crc >> 1
```

覆盖范围：视觉帧字节 0..6，遥测帧字节 0..35，握手帧字节 0..3，ACK 与复位帧字节 0..2。

### 4.3 握手、ACK 与复位

| 方向 | 帧格式 | 长度 | 触发 |
|---|---|---|---|
| F103 → OpenMV | `A5 MODE FLAGS FE CRC8` | 5 B | 每 100 ms，直到收到 ACK |
| OpenMV → F103 | `5A MODE FE CRC8` | 4 B | 收到合法握手后连发 3 次 |
| OpenMV → F103 | `5B 5B 5B CRC8` | 4 B | 上电时连发 3 次，清除握手锁存 |

- `MODE`：0 default、1 pitch-only、2 yaw-only、3 both；F103 用编译期宏 `DART_MODE`（默认 `DART_MODE_BOTH`）。
- `FLAGS`（握手帧）bit0 = IMU 就绪。
- F103 只在 ACK 的 `MODE` 与自身 `DART_MODE` 相同、且 CRC 正确时置 `attitude_tx_armed = 1`；复位帧可将其清 0，从而允许重新握手。
- 握手使用阻塞发送（超时 5 ms），只在 armed 前发生。

### 4.4 视觉上行帧（OpenMV → F103，8 字节）

```text
AA  xH xL  yH yL  recognized  FF  CRC8
```

| 字节 | 内容 |
|---|---|
| 0 | `0xAA` |
| 1-2 | X 偏移，int16 大端，相对制导中心，向右为正 |
| 3-4 | Y 偏移，int16 大端，相对制导中心，向下为正 |
| 5 | `recognized`：1 = 识别到目标，0 = 未识别 |
| 6 | `0xFF` |
| 7 | CRC8（覆盖 0..6） |

- 制导中心由 OpenMV 的 `GUIDE_CX/GUIDE_CY` 决定（当前 `(160, 120)`）；F103 以 `(0, 0)` 为中心，不保存像素坐标。
- 偏移超过 `|dx| ≤ 160`、`|dy| ≤ 120` 时按无目标处理。
- 未识别时发送 `x = 0, y = 0, recognized = 0`。
- OpenMV 在 `uart.txdone()` 为假时直接丢帧并累加 `TX_SKIP_COUNT`，不做排队。

### 4.5 遥测下行帧（F103 → OpenMV，37 字节，50 Hz）

```text
55  gxH gxL gyH gyL gzH gzL
    pH  pL  yH  yL  rH  rL
    oPH oPL oYH oYL oRH oRL
    mode state flags
    losYawH losYawL losPitchH losPitchL
    s1H s1L s2H s2L s3H s3L s4H s4L
    dbgFlags FE CRC8
```

| 字节 | 内容 | 单位 |
|---|---|---|
| 0 | `0x55` | — |
| 1-2 | 陀螺 X | 0.1 °/s |
| 3-4 | 陀螺 Y | 0.1 °/s |
| 5-6 | 陀螺 Z | 0.1 °/s |
| 7-8 | 当前 pitch | 0.01° |
| 9-10 | 当前 yaw | 0.01° |
| 11-12 | 当前 roll | 0.01° |
| 13-14 | 输出目标 pitch | 0.01° |
| 15-16 | 输出目标 yaw | 0.01° |
| 17-18 | 输出目标 roll | 0.01° |
| 19 | mode（0..4，4 = debug） | — |
| 20 | state（0..7，7 = debug） | — |
| 21 | flags | — |
| 22-23 | LOS yaw 增量（相对上电 1 s 参考角） | 0.01° |
| 24-25 | LOS pitch 增量（同上） | 0.01° |
| 26-27 | 舵机 1 角度 | 0.1° |
| 28-29 | 舵机 2 角度 | 0.1° |
| 30-31 | 舵机 3 角度 | 0.1° |
| 32-33 | 舵机 4 角度 | 0.1° |
| 34 | 调试标志：bit0 参考角已捕获 | — |
| 35 | `0xFE` | — |
| 36 | CRC8（覆盖 0..35） | — |

当前姿态角按 `DART_INS_*` 映射：`pitch = -INS.Roll`、`roll = INS.Pitch`、`yaw = INS.Yaw`；陀螺通道为原始机体轴 X/Y/Z。

flags 位定义：

| 位 | 名称 | 含义 |
|---|---|---|
| bit0 | `DART_ATT_FLAG_LINK_VALID` | 250 ms 内有有效视觉帧 |
| bit1 | `DART_ATT_FLAG_TARGET_VALID` | 目标仍有效（120 ms 保持窗口内） |
| bit2 | `DART_ATT_FLAG_IMU_READY` | IMU 已完成初始化与标定 |
| bit3 | `DART_ATT_FLAG_HANDSHAKE_DONE` | 已收到 ACK，armed |
| bit4 | `DART_ATT_FLAG_OUTPUT_VALID` | 输出目标角有效（上升/下降段） |

> **调试模式（MODE=4 / STATE=7）**：编译期把 `DART_MODE` 设为 `DART_MODE_DEBUG`。
> 不做起飞检测、不驱动舵机（PWM 保持中位），只运行视觉引导并上报；
> 上电 1 s 后的静止姿态作为 LOS 增量的零点；舵机角按 1550 µs=0°、±1000 µs=±90° 换算。
> 该模式下 OpenMV 仍正常显示与记录 CSV，录像仍只在起飞后启动。

### 4.6 发送时序与调度

- 遥测固定在 `LED_Task` 中每 20 ms 发一帧，使用 `HAL_UART_Transmit_IT` + 静态缓冲。
- 发送前检查 `huart1.gState == HAL_UART_STATE_READY`；上帧未发完则跳过本帧，避免覆盖缓冲。
- 遥测与握手同用 USART1 TX，握手仅在 armed 前发送，因此正常飞行时总线上只有 37 字节遥测和 8 字节视觉帧。

### 5.1 文件职责

> `Control_Task.c` 与 `ctl_task.h` 为 **GBK 编码**，用其他编辑器修改时不要存成 UTF-8，否则 Keil 中中文注释会乱码。

### 5.2 IMU 与姿态

`INS_Task()` 每 1 ms 执行一次：

1. `BMI088_Read()` 读取加速度与角速度，复制到全局 `INS`。
2. `IMU_QuaternionEKF_Update()` 用陀螺与加速度融合，更新 `INS.Yaw/Pitch/Roll`。
3. 把导航系重力转到机体系并相减，得到去重力加速度，再经一阶低通（`AccelLPF = 0.0085`）得到 `INS.MotionAccel_b`。
4. `dt` 异常（`<= 0` 或 `> 20 ms`）时回退 1 ms。

轴映射只在 `ctl_task.h` 处理一次：

```c
DART_INS_PITCH_DEG(ins)   → -(ins->Roll)
DART_INS_ROLL_DEG(ins)    → ins->Pitch
DART_INS_YAW_RATE_RAD_S   → Gyro[2]
DART_INS_PITCH_RATE_RAD_S → -Gyro[1]
DART_INS_ROLL_RATE_RAD_S  → Gyro[0]
```

阅读或修改控制代码时不要在混控处再次交换 pitch 与 roll。

**BMI088 标定**：`BMI088_init(..., 1U)` 执行 6000 点静止采样，计算陀螺零偏；期间机体必须静止。寄存器读回失败时直接返回错误码，由 `IMU_Task` 每 100 ms 重试，因此“没插 IMU / SPI 松动”表现为 LED 停在蓝灯并循环重试，而不是静默卡死。

### 5.3 控制初始化

`control_Init()`：

1. 关中断清空 `DartControl`（保留 `imu_ready`）。
2. 只计算一次焦距：`VisionFocalPx = DART_CAMERA_FOCAL_PX`（当前 640×480 读出窗口取 961 px）。
3. 舵机遥测初值置中位 1550 µs。
4. 初始化 5 个 PID：yaw / pitch 各有“自稳”和“视觉”两套参数，roll 一套。
5. 状态置 `READY`，记录 `last_control_ms` 与 `control_start_ms`。
6. `vision_uart_init()`：中止旧接收、清 ORE、启动单字节中断接收。

`servo_Init()` 启动 TIM2 四路 PWM 并回中；四路全部启动成功才置 `servo_ready`。

### 5.4 状态机

```text
READY ──IMU ready──> IMU_READY ──500 ms + PWM 启动成功──> SERVO_READY
      ──起飞加速度确认 5 周期──> LAUNCHED ──采 5 帧 + 250 ms──> ASCENT
      ──pitch < 5° 连续 25 周期且已上升 300 ms──> DESCENT
```

`DART_STATE_VISION_ERROR` 不是飞行阶段，只在起飞前视觉链路异常时覆盖对外显示状态（LED 闪白）。

`set_state()` 同时更新时间戳 `state_enter_ms`，各种等待与确认门槛都基于它。

各状态进入条件：

| 转换 | 条件 |
|---|---|
| `READY → IMU_READY` | `imu_ready = 1` |
| `IMU_READY → SERVO_READY` | 已等待 500 ms 且 `servo_Init()` 成功 |
| `SERVO_READY → LAUNCHED` | `DART_LAUNCH_X_SIGN × MotionAccel_b[0] ≥ 22.0` 连续 5 周期 |
| `LAUNCHED → ASCENT` | 姿态采样满 5 帧且已等待 250 ms |
| `ASCENT → DESCENT` | 已上升 ≥ 300 ms，且映射后 pitch < 5° 连续 25 周期（约 50 ms） |

### 5.5 起飞检测

```c
launch_accel = DART_LAUNCH_X_SIGN * ins_snapshot.MotionAccel_b[0];
if (launch_accel >= DART_LAUNCH_ACCEL_THRESHOLD) 计数 +1; 否则清零;
```

计数达到 5 才确认起飞。确认后：复位全部 PID、清空姿态累加与各段标志、用当前姿态作为起飞参考、进入 `LAUNCHED` 并立刻执行一次上升段控制。

进入 `LAUNCHED` 后连续采集 5 帧姿态：yaw 用圆均值（`atan2(Σsin, Σcos)`，处理 ±180° 跳变），pitch/roll 用算术平均。

### 5.6 上升段控制

`run_ascent_stabilization()` 每 2 ms 执行，三条轴独立处理。

**yaw**：若 `DART_MODE != PITCH` 且目标有效，走视觉 yaw：

```text
camera_yaw_rate = sign × (视觉角速率 + 机体 yaw 角速率)
yaw_command     = LOS_yaw + T_d × camera_yaw_rate
                  （再乘 cos(roll) 投影到机体 yaw 轴，限幅 ±20°）
输出            = DART_ASCENT_VISION_YAW_OUTPUT_SIGN × 视觉 PID(yaw_command)
```

视觉激活/退出各复位一次 `yaw_vision_pid`，避免积分残留。目标失效时立即回到起飞 yaw 自稳，输出目标角报告为 `launch_yaw_deg`。

**pitch**：两阶段补偿。

```text
若映射后 pitch < 目标角(+25°)：记 below_target = 1
否则若此前 below_target：ascent_pitch_done = 1，复位 pitch PID

未 done 时：
  尚未 below_target（角度仍高于目标）→ 固定抬升 DART_ASCENT_PITCH_LIFT_US = 100 µs
  已 below_target                     → pitch PID 闭环到目标角
目标角报告为 +25°
done 之后：pitch 输出 0，进入下降段时也立即置 done 并清零输出
```

**roll**：默认 `DART_ASCENT_ROLL_COMPENSATION_ENABLE = 0`，即保持起飞瞬间 roll（自稳）；置 1 时先固定抬升，越过补偿目标后转 PID 闭环。

三条轴的输出经 `write_servo_outputs()` 混控后写入 TIM2。

### 5.7 视觉滤波

`update_vision_filter()` 每次控制周期执行，两种模式由 `DART_VISION_FILTER_MODE` 选择，**默认 `DART_VISION_FILTER_RAW_RATE`**。

数据入口：USART1 中断解析出 8 字节帧后写入无锁 mailbox（`x`、`y`、`recognized`、`tick_ms`、递增 `sequence`）。控制任务用两次读 `sequence` 的方式取一致快照。

测量有效性：`recognized = 1` 且 `|dx| ≤ 160`、`|dy| ≤ 120`。

**RAW_RATE 模式**：

- 位置角直接取当前帧 `atan((pixel - 0) / focal)`，不做低通。
- 角速率由相邻有效帧差分得到；首帧、重新捕获首帧、无目标帧一律置 0。
- 帧间隔合法范围 5–100 ms；速率经一阶低通（`RC = 20 ms`），并限幅 ±360 °/s。
- 位置不做滤波，因此不存在 EKF 的预测滞后。

**EKF 模式**（可切回，代码保留）：

- 状态 `[视线角, 视线角速率]`，匀角速度模型，过程噪声 5.0、量测噪声 9.0 px²。
- 量测模型 `pixel = center + focal × tan(angle)`，雅可比 `focal × (1 + tan²)`。
- 两轴创新量都必须落在 ±180 px 内才接受整帧，否则整帧丢弃。

两种模式共用后续逻辑：

| 判据 | 行为 |
|---|---|
| 250 ms 内无新帧 | `link_valid = 0` |
| 120 ms 内有过目标 | `valid = 1`（可使用） |
| 超过 500 ms 无目标 | 复位两轴滤波器，`valid = 0` |
| 启动后 1 s 仍无链路 | 起飞前置 `VISION_ERROR`，LED 闪白 |

### 5.8 下降段引导

`run_descent_guidance()` 流程：

1. roll 仍按起飞 roll 保持（补偿开启时按补偿目标），写入遥测。
2. 目标无效时：
   - 若锁存开启、此前识别过目标、且距最后目标 ≤ 500 ms：保持上一次相对指令，yaw/pitch 视觉 PID 继续跟踪，直接输出并返回。
   - 否则：退出视觉（复位 yaw/pitch 视觉 PID）、清零目标角、yaw 回到起飞方向、pitch 输出 0、四舵按混控回中。
3. 目标有效时，首次进入复位两个视觉 PID，然后计算：

```text
camera_yaw_rate   = sign × (视觉 x 角速率 + 机体 yaw 角速率)
camera_pitch_rate = sign × (视觉 y 角速率 - 机体 pitch 角速率)
yaw_command       = LOS_yaw   + T_d × camera_yaw_rate
pitch_command     = LOS_pitch + T_d × camera_pitch_rate
（角速率限幅 ±30 °/s，指令限幅 ±20°）
```

4. 按当前 roll 把相机平面指令旋转到机体轴：

```text
yaw_body   =  cos(roll) × yaw_camera   + sin(roll) × pitch_camera
pitch_body = -sin(roll) × yaw_camera   + cos(roll) × pitch_camera
```

5. 单轴模式：`DART_MODE_PITCH` 时 yaw 指令与输出置 0 并复位 yaw 视觉 PID；`DART_MODE_YAW` 时对 pitch 做同样处理。
6. 目标角写入遥测 `target_*` 与 `output_*`；pitch 上报值取 `-pitch_command`（下降段方向修正）。
7. 输出：`yaw_output = -1 × 视觉 PID(yaw_command)`、`pitch_output = -1 × 视觉 PID(pitch_command)`，roll 保持，混控写舵机。

这里不是完整经典比例导引：没有距离、速度与闭合速度，只有视线角与惯性系视线角速率前视项（前视追踪，lead pursuit）。

### 5.9 PID

通用实现在 `controller.c`，控制任务通过 `calculate_axis_pid()` 调用：

```c
rate_deg_s = rate_rad_s × RAD_TO_DEG;
PID_Calculate(pid, rate_deg_s, rate_deg_s + error);   // Ref - Measure == error
```

因此角度误差仍进入比例与积分，而微分由钩子函数 `gyro_rate_derivative()` 直接给出 `Dout = -Kd × 角速度`，不再对误差求导（`OLS_ORDER = 0`）。

| 机制 | 行为 |
|---|---|
| 输出限幅 | ±420 µs |
| 积分限幅 | ±120 µs |
| 死区 | 0.20°；死区内 `Output = Iout + Dout`，保留积分与角速度阻尼 |
| 积分分离参数 | `A = 10`、`B = 2`，但 `ChangingIntegrationRate` 未启用 |
| 输出 / 微分低通 | RC 均为 0.01 |
| dt 来源 | DWT 实测；`dt <= 0` 或 `> 20 ms` 回退 2 ms |
| 复位时机 | 起飞确认、进入下降段、视觉激活/退出、状态切换 |

两套参数：自稳（yaw 5.0/0.01/0.5、pitch 10.0/0.05/0.5）与视觉（yaw 5.0/0.1/0.5、pitch 10.0/0.1/5.0），roll 固定 10.0/0.01/1.0。视觉 Kd 的量纲是 µs/(°/s)，符号需在机架上确认。

### 5.10 混控与舵机输出

```c
pitch *= DART_PITCH_OUTPUT_SIGN;   // +1
yaw   *= DART_YAW_OUTPUT_SIGN;     // -1
roll  *= DART_ROLL_OUTPUT_SIGN;    // -1

m0 =  pitch + yaw + roll
m1 =  pitch - yaw + roll
m2 = -pitch - yaw + roll
m3 = -pitch + yaw + roll
```

每个通道依次：限幅到 `±(2550-1550) µs` 与 `±(1550-550) µs` → 加中位 1550 µs → 与上一周期比较，单周期变化不超过 30 µs → 写 TIM2 比较寄存器。

PID 输出是相对舵机中位的偏置，不是绝对 PWM 值。步进限制会掩盖瞬态方向错误，验证舵面时应观察完整行程。

### 5.11 遥测发送

`attitude_telemetry_send()` 在 `LED_Task` 中每 20 ms 调用：

- 未 armed 或 IMU 未就绪直接返回；`huart1` 忙时跳过本帧。
- 关中断复制姿态、陀螺与输出角（约数十字节），保证同一帧数据一致。
- 角度 ×100、角速度 ×10 转 int16 大端填充，LOS 增量与四路舵机角一并打包，计算 CRC8，`HAL_UART_Transmit_IT` 发送 37 字节。
- 使用静态发送缓冲，因此依赖 `gState` 判断上一帧是否完成。

### 5.12 LED

| 状态 | 颜色 | 引脚电平（低有效） |
|---|---|---|
| `READY` | 蓝 | R0 G0 B1 |
| `IMU_READY` | 绿 | R0 G1 B0 |
| `SERVO_READY` | 青 | R0 G1 B1 |
| `LAUNCHED` | 红 | R1 G0 B0 |
| `ASCENT` | 黄 | R1 G1 B0 |
| `DESCENT` | 紫 | R1 G0 B1 |
| `VISION_ERROR` | 白闪 | 200 ms 翻转 |

`VISION_ERROR` 只覆盖对外显示，不改变 `DartControl.flight_state`；起飞后不再显示，视觉失联由下降段目标丢失逻辑处理。

### 5.13 并发与中断

- `INS` 由 IMU 任务每 1 ms 更新，控制任务用关中断 `memcpy` 取快照。
- 视觉 mailbox 用递增 `sequence` 实现单生产者/单消费者无锁读：读前读后序号一致才采用。
- USART1 使用单字节中断接收，每字节一次 IRQ；115200 下满速约 11 520 IRQ/s。协议靠 SOF/EOF/CRC 与逐字节滑窗重新同步。
- ORE 等错误在 `control_uart_error_callback()` 中清标志并重启接收，帧索引清零。
- USART1 中断优先级 5 等于 `configLIBRARY_MAX_SYSCALL_INTERRUPT_PRIORITY`；回调中若需 RTOS API 只能用 `FromISR` 版本，且不要做耗时操作。

## 6. OpenMV 视觉端

### 6.1 启动与握手

`main.py` 顶层依次执行：`=== BOOT ===` → `UART(3, 115200, read_buf_len=2048)` → 传感器初始化 → `wait_for_handshake()` → 主循环。

`wait_for_handshake()`：

1. 连发 3 次复位帧 `5B 5B 5B CRC`，每次间隔 5 ms，清空接收缓冲。
2. 逐字节搜索 `A5`，校验 EOF 与 CRC，MODE 必须 ≤ 3。
3. 收到合法帧后回 3 次 `5A MODE FE CRC`，间隔 2 ms，再次清空缓冲并返回 mode。

因此 **不接 F103 时脚本不会进入主循环**，会每秒打印 `still waiting, buf_len = N`。

### 6.2 图像与目标检测

| 项目 | 值 |
|---|---|
| 帧尺寸 / 格式 | QVGA 320×240，RGB565 |
| 传感器读出窗口 | `(0, 700, 640, 480)` |
| 检测 ROI | `(0, 0, 320, 240)`，随目标动态收缩 |
| 制导中心 | `(160, 120)`，ROI 中心 |
| 绿色阈值 | L 9–100，A −102–−25，B 0–127 |
| 曝光 / 增益 | 固定 800 µs / 20 dB，白平衡关闭 |
| 启动跳帧 | 1500 ms |

检测流程：`find_blobs()` 在 `cur_roi` 内找色块 → 取面积最大者 → 以 `blob.rect` 更新跟踪 ROI（外扩 40 px 并裁剪到画面内）→ 未识别时 ROI 复位为全画面 → 5 帧时间中值滤波抑制跳点 → 计算 `dx = cx - 160`、`dy = cy - 120`。

单轴模式下：MODE_PITCH 时 `dx = 0`，MODE_YAW 时 `dy = 0`。

### 6.3 上行发送

`send_target(dx, dy)` 与 `send_no_target()` 都先检查 `uart.txdone()`，忙则丢帧；帧内偏移为有符号 16 位大端，CRC8 覆盖前 7 字节。写串口耗时超过 20 ms 会打印 `[DEBUG] write slow` 并累加 `TX_SLOW_COUNT`。

### 6.4 遥测解析与屏幕

`poll_telemetry()` 每次主循环调用：

- 读空串口缓冲，追加到 `telem_buf`，按 37 字节切帧，校验 EOF 与 CRC。
- 有效帧更新陀螺、姿态、输出角、LOS 增量、四路舵机角、mode、state、flags，并锁存飞行状态：状态落在 3..5 即 `flight_seen = True`；首次收到 5 记录 `descent_seen_ms`。
- `telem_frames` 累加，帧数超过 200 字节缓冲时清空并打印 `telem_buf overflow`。
- 300 ms 无有效帧则 `telem_link = 0`。

屏幕叠加（左上角逐行）：

```text
FPS:<fps>
t=<ms> T:<有效遥测帧数>
P:<pitch> Y:<yaw> R:<roll>      无链路时显示 --
GX:<gx> GY:<gy> GZ:<gz>
OP:<out_pitch> OY:<out_yaw> OR:<out_roll>   flags bit4 无效时显示 --
M:<mode> S:<state> L:<link> V:<目标有效>
<录像文件名>                      仅录像时
```

识别到目标时额外画红框与 `Found! X=.. Y=..`，并画蓝色跟踪 ROI 矩形。

### 6.5 录像

- 使用 `image.ImageIO(path, "w")` 文件流，逐帧 `write(img)`，不在内存缓存整段视频。
- 文件为 `rec_00001.bin`、`rec_00002.bin`…，存入可写的 `/sdcard` 或 `/sd`。
- 触发：收到状态 3..5 的第一帧开始；下降后 3 s 停止；最长 30 s；未起飞不录。
- 默认不限制帧率（`RECORD_INTERVAL_MS = 0`）；设为正数才启用最小写间隔。
- 每秒 `sync()`（旧固件无该方法时退回 `os.sync()`）；正常结束、写异常都会关闭文件。
- QVGA RGB565 每帧约 154 KB，30 s 满速录制可达上百 MB；写卡会占用主循环时间。

### 6.6 遥测 CSV

与录像并行，`telem_log` 在首次进入状态 3..5（或调试状态 7）时创建 `telem_00001.csv` 等文件，逐帧追加：

```text
t_ms,frame,mode,state,flags,gx_dps,gy_dps,gz_dps,
pitch_deg,yaw_deg,roll_deg,out_pitch_deg,out_yaw_deg,out_roll_deg,
los_yaw_deg,los_pitch_deg,s1_deg,s2_deg,s3_deg,s4_deg
```

停止条件与录像一致（下降后 3 s 或 30 s 上限），每秒 `flush()` 一次。SD 不可写或写失败时停止记录并打印 `[DEBUG] telem log ...`，不影响视觉与串口。

### 6.7 回放与导出

`imageio_playback.py` 在 OpenMV 上独立运行（先停止 `main.py`）：

- 默认自动搜索 `/sdcard`、`/sd`、`/flash`、`/` 与当前目录，选择编号最大的 `rec_XXXXX.bin`。
- `STREAM_PATH` 指定文件时先校验存在；不存在则列出候选，不会误开别的文件。
- 使用 `csi.CSI()` + `ImageIO.read(copy_to_fb=True, loop=False, pause=True)` 按原始帧间时间播放。
- `EXPORT_MJPEG = True` 时在同目录生成同名 `.mjpeg`，已存在则拒绝覆盖，原 `.bin` 保留。
- 读到 `Frames played: N` 即结束；损坏文件会保留已读前缀并报告错误。

### 8.5 上电验证顺序

1. **不装动力**，F103 与 OpenMV 同时上电，确认握手、遥测、屏幕角度与 LED。
2. 静止时 P/Y/R 应接近 0（或已知安装角），LED 蓝 → 绿 → 青。

8. 小增益、短时、低速验证 PID 与引导。

## 9. 已知问题与风险

### 9.1 RAM 余量小（中高）

最近一次链接结果 `RW_IRAM1 = 19152 / 20480 B`，只剩 **1328 B**。这已包含 2 KB 主栈、512 B 传统 heap、10 KB FreeRTOS heap 与全部全局变量。新增缓冲、任务或栈都可能直接导致链接失败或运行时栈溢出；改完必须重新看 `.map`。

### 9.2 无绝对航向，yaw 会漂移（高）

没有磁力计或 GPS，yaw 以起飞瞬间为参考；静止标定只能减小固定零偏，温漂造成的长期漂移无法从原理上消除。上升段保持的是相对 yaw，不是地理航向。

### 9.3 引导模型简化（中高）

只有像素视线角，没有距离、速度与闭合速度，属于静止目标下的前视追踪；未建模相机延迟、畸变、安装角与滚转引起的图像旋转。前视时间与速率死区需要实机整定，焦距与视线偏置需要标定。

### 9.4 没有着陆 / 结束状态（中）

进入 `DESCENT` 后不会退出。落地后若仍有视觉帧会继续打舵；目标失效只回中，没有“已落地”判定、搜索或失控保护。

### 9.5 录像吞吐与帧率（中）

原生 RGB565 每帧约 154 KB。按 30 FPS 估算写入约 4.6 MB/s，普通 SD 卡可能跟不上；写卡期间主循环被拉长，串口接收可能溢出，遥测与视觉帧都可能丢。

### 9.6 单字节中断接收（中）

115200 下满速约 11 520 次 IRQ/s，当前负载不高但中断频繁；高负载时可能丢字节，只能靠 CRC 与滑窗重新同步恢复。后续可改 USART DMA + IDLE。

### 9.7 握手依赖（中）

OpenMV 不握手就不进入主循环，单独调试视觉不方便；OpenMV 中途复位会触发重新握手；ACK 的 MODE 必须与 F103 的 `DART_MODE` 完全一致。

### 9.8 参数未整定（中）

22 m/s²、5 周期、300 ms、5°、25 周期、前视 0.15 s/±5°、两套 PID 都是代码默认值，没有真实飞行数据支撑。起飞检测依赖去重力加速度，安装方向或符号错误会直接导致不触发或误触发。

### 9.9 舵机方向与混控未验证（高，安全）

四个舵机编号、正方向、机械零位与混控符号必须拆动力逐轴确认。单周期 30 µs 步进会掩盖瞬态方向错误，测试时要观察完整行程。

### 9.10 BMI088 标定阻塞（中）

单轮 6000 点、带延时，约数秒；条件不满足会持续重试。标定期间 `imu_ready = 0`，控制任务直接返回。上电必须静止，否则零偏错误。

### 9.11 工程卫生（中）

`Control_Task.c`、`ctl_task.h`、`controller.c`、`BMI088driver.c` 仍为 GBK，其余多为 UTF-8；工程内保留大量未参与编译的 RoboMaster 框架代码（`ui.c`、`judge_protocol.c`、`drv_can.c`、`Correspondence_Task.cpp` 等），阅读时应直接跳过。

### 9.12 其他

- USB PCD、USART3、TIM3 的初始化已从 `main()` 删除，但对应源文件仍参与编译。
- `VISION_ERROR` 会覆盖遥测 state 但不改变真实状态，排查时看 flags 与 P/Y/R。
- `T` 持续增加但 YPR 不变，说明遥测在收、IMU 未更新；`T` 停止增加，查串口、供电或 SD 写入。
- `main.py` 使用 `sensor` + `pyb.UART`，回放脚本使用 `csi`，两者依赖具体 OpenMV 固件版本。

## 10. 排障手册

| 现象 | 可能原因 | 检查 |
|---|---|---|
| OpenMV 一直 `waiting handshake...` | F103 未上电/未烧录；PA9 未接 | 量 PA9 波形；确认 F103 LED 至少蓝色；确认 `openmv_handshake_send()` 被调用 |
| 握手成功但屏幕 `P:--` | 未 armed；遥测被截断；接触不良 | 确认收到 ACK；逻辑分析仪看 37 B 帧；检查 `huart1.gState` |
| `L:0` 且角度 `--` | 300 ms 内无有效遥测 | 检查波特率、CRC、接线、F103 是否在发 |
| `T` 增加但 YPR 不变 | 遥测在收、IMU 未更新 | 看 GX/GY/GZ；查 BMI088 初始化、标定、SPI |
| `T` 不增加 | 接收停、缓冲溢出、供电跌落 | 查 SD 写入、串口错误回调、电源 |
| `V:1` 但无 `Found!` | 有帧但未识别目标 | 查阈值、光照、目标颜色、ROI |
| 有 `Found!` 但飞控无反应 | 偏移超范围、CRC 错、单轴置零 | 看 dx/dy 是否在 ±160/±120；查 CRC；确认 mode |
| 不录像 | 未收到状态 3..5；SD 不可写 | 看 `record start:`；查 `RECORD_DIR`；确认遥测 state |
| `record open fail` | SD 未挂载 / 只读 / 编号耗尽 | 换卡、格式化为 FAT、清理旧录像 |
| 录像文件很大 | 原生 RGB565 未压缩 | 正常；用回放脚本导出 MJPEG |
| 回放找不到录像 | 不在搜索目录；文件名不符 | 看脚本列出的目录；设 `STREAM_PATH` |
| `Cannot open ImageIO recording` | 文件损坏或不是 ImageIO 格式 | 确认是当前 `main.py` 所录；检查文件头 |
| 导出 MJPEG 失败 | 输出已存在 | 改名或删旧 `.mjpeg` |
| Keil 编译报错 | 器件包缺失、路径变化、编码被改 | 按本机 Pack 配置；确认 GBK 文件未被转 UTF-8 |
| 舵机不动 | PWM 未启动、舵机未就绪、供电不足 | 看是否到 `SERVO_READY`；量 PA0–PA3；单独供电 |
| 舵机方向反 | 轴符号、混控、接线 | 拆动力，逐轴改 `DART_*_OUTPUT_SIGN` 或混控 |
| 起飞不触发 | 阈值太高、方向反、加速度未去重力 | 看 `MotionAccel_b[0]`；确认 `DART_LAUNCH_X_SIGN` |
| 提前进入下降 | pitch 噪声、阈值、确认数太小 | 看 P 曲线；加大确认数或调整阈值 |
| 下降段乱打舵 | 目标无效、引导过强、符号错 | 看 flags bit1；降低 N 与限幅；查相机符号 |
| 上电反复标定 | 机体未静止、振动 | 静止放置；查陀螺零偏条件 |

```text
    draw_overlay()             屏幕叠加
```

### 12.3 术语

| 术语 | 含义 |
|---|---|
| INS | Inertial Navigation System，姿态/惯性解算 |
| EKF | Extended Kalman Filter，扩展卡尔曼滤波 |
| LOS | Line of Sight，视线角 |
| PN | Proportional Navigation，比例导引；本文改用其静止目标特例“前视追踪” |
| ASCENT / DESCENT | 上升段 / 下降段 |
| LAUNCHED | 已检测到起飞、正在采集起飞姿态 |
| SERVO_READY | 舵机就绪、等待起飞 |
| armed | 握手完成、允许发送遥测 |
| mailbox | 中断与任务之间传递视觉帧的无锁结构 |
| ROI | Region of Interest，检测区域 |
| QVGA | 320×240 |
| ImageIO | OpenMV 原生图像流接口 |
| DWT | Cortex-M 周期计数器，用于微秒级计时 |
| OLS | 最小二乘微分估计，本工程已停用（`OLS_ORDER = 0`） |
| X 尾混控 | 四个舵面按 X 形分配 pitch/yaw/roll |
| GBK | 中文编码，部分 C 文件使用 |
